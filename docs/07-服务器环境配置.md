# 服务器环境配置（AutoDL · A800）

> 写于 2026-10-30。版本兼容性已核实：flash-attn 的 GitHub 发布页、上游 `requirements.txt`。
> 命令是按文档和版本信息写的，还没有在实例上实际跑过。遇到报错，按实际情况调整，并把问题和解法记进 [06-进度.md](06-进度.md)。

---

## 1. 租实例时怎么选

| 项 | 选什么 | 理由 |
|---|---|---|
| GPU | A800 80GB × 1 | D05（R21 定） |
| 主机 | 挑**空闲卡 ≥ 2** 的主机 | D5–D6 可能要升到 2 卡，同一台主机有空闲卡才升得上去 |
| 镜像 | **PyTorch 2.8.0 / Python 3.12 / CUDA 12.x**（选 2.8.0 后，CUDA 用它默认给的 12.x） | 见 §2 |
| 数据盘 | 默认免费 50GB，不扩容 | 权重、TinyGSM、缓存加起来约 20GB |
| 计费 | 先看包周价格，不高于"按量单价 × 70 小时"就包周 | 05 §0 |

## 2. 为什么选 PyTorch 2.8.0，不选 2.12.1

| | 2.8.0 + CUDA 12.x | 2.12.1 + CUDA 13.0 |
|---|---|---|
| 和作者的环境比 | 最接近作者用的 torch 2.7.0 | 新了 5 个版本 |
| `flash_attn`（代码开头就 import，位置编码要用它的 kernel） | 有官方预编译包：`flash_attn 2.8.3.post2`，支持 torch 2.4–2.8、CUDA 12、Python 3.12，**直接 pip 安装** | **没有预编译包**（官方包只到 torch 2.8 + CUDA 12），要从源码编译，通常要几十分钟，还可能失败 |
| 其他依赖（lightning 2.5.1、transformers 4.45 等） | 都是 2025 年的版本，和 torch 2.8 时间上接近 | 没验证过 |

2.5.1 也有预编译包，但比作者的版本旧，没必要选。

## 3. 开机后的配置步骤

### 3.1 检查环境

```bash
nvidia-smi
python -c "import torch; print(torch.__version__, torch.version.cuda, torch.cuda.is_available(), torch._C._GLIBCXX_USE_CXX11_ABI)"
```

记下最后一个值（True / False），3.3 选 flash-attn 安装包时要用。

### 3.2 拉代码

```bash
source /etc/network_turbo          # AutoDL 学术加速，覆盖 github 和 huggingface
cd /root && git clone https://github.com/NonEspoir/dllm.git
```

### 3.3 装 flash-attn（预编译包，约 256MB）

按 3.1 打印的 ABI 值，二选一：

```bash
# ABI = True
pip install "https://github.com/Dao-AILab/flash-attention/releases/download/v2.8.3.post2/flash_attn-2.8.3.post2%2Bcu12torch2.8cxx11abiTRUE-cp312-cp312-linux_x86_64.whl"
# ABI = False
pip install "https://github.com/Dao-AILab/flash-attention/releases/download/v2.8.3.post2/flash_attn-2.8.3.post2%2Bcu12torch2.8cxx11abiFALSE-cp312-cp312-linux_x86_64.whl"
```

### 3.4 装其他依赖

```bash
cd /root/dllm/code
pip install numpy==1.26.4
grep -v "lm-evaluation-harness" requirements.txt > /tmp/req.txt
pip install -r /tmp/req.txt
unset http_proxy https_proxy       # 装完关掉学术加速
```

- **先把 numpy 固定到 1.26.4**：这是作者用的版本。镜像里很可能是 numpy 2.x，而 `requirements.txt` 固定的 pandas 2.2.1、scikit-learn 1.4.0 是按 numpy 1.x 编译的，遇到 numpy 2 会在 import 时报错。
- **去掉 `lm-evaluation-harness`**：它要从 GitHub 源码安装，而 GSM8K 评测用不到它。
- `requirements.txt` 没有固定 torch，所以不会覆盖镜像自带的 torch 2.8。

### 3.5 缓存目录放到数据盘

系统盘只有 30GB，HuggingFace 的缓存默认放在系统盘，要改到数据盘：

```bash
cat >> ~/.bashrc <<'EOF'
export HF_HOME=/root/autodl-tmp/hf_cache
export HF_ENDPOINT=https://hf-mirror.com
export TORCH_FORCE_NO_WEIGHTS_ONLY_LOAD=1
EOF
source ~/.bashrc
```

`TORCH_FORCE_NO_WEIGHTS_ONLY_LOAD=1` 是上游所有脚本里都设置的环境变量：torch 2.6 起 `torch.load` 默认只加载纯权重，而这些 checkpoint 里还有别的对象，不设会加载失败。

### 3.6 下载 checkpoint

```bash
mkdir -p /root/autodl-tmp/checkpoints
huggingface-cli download jdeschena/s-flm tinygsm/mdlm.ckpt --local-dir /root/autodl-tmp/checkpoints
# 加分项用，可以晚点下
# huggingface-cli download jdeschena/s-flm tinygsm/duo.ckpt --local-dir /root/autodl-tmp/checkpoints
```

tokenizer（SmolLM-135M）和 GSM8K 会在首次运行时自动从 hf-mirror 下载。

### 3.7 冒烟测试

```bash
cd /root/dllm/code
python -c "import flash_attn, flash_attn.layers.rotary, lightning, transformers, hydra; print('imports ok')"
```

能打印 `imports ok`，环境就算配好了。下一步是 D1 的冒烟测试和复现（[06-进度.md](06-进度.md)「下一步」）。

## 4. 在服务器上改代码要准备的两件事

1. **推送权限**：仓库是公开的，`git clone` 不需要登录，但从服务器 `git push` 需要认证。二选一：
   - 在服务器上生成 SSH 密钥，把公钥加到 GitHub，然后把远程地址改成 `git@github.com:NonEspoir/dllm.git`；
   - 用 GitHub 的 Personal Access Token 走 HTTPS。
   推送时先 `source /etc/network_turbo`。
2. **如果在服务器上运行 Claude Code**：它需要访问 Anthropic 的 API，而 AutoDL 的学术加速只覆盖 GitHub 和 HuggingFace，可能需要你自己配网络。
