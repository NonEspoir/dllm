# 开销预算（AutoDL · RTX 4090）

> 写于 2026-10-30（D0 结束时）。D1 实测后用实际单步耗时重算一遍，并在 [06-进度.md](06-进度.md) 里记录实际花费，与这里的预算对照。
> 所有耗时都是按规格推算的估计，**误差约 ±50%**。

---

## 0. 结论（10-30 修订：不刻意省钱）

你在 R16 说不需要过于省钱、每次先在 Mac 上跑太麻烦。所以工作方式改为：**工作时段 4090 实例一直开着，代码改完直接在服务器上跑，不在 Mac 上执行。** 这样花费主要由"开机时长"决定，而不是"实际计算时长"。

| 项 | 时长 | 费用（按 ¥2/h） |
|---|---|---|
| 实例开机时长（D1–D7，按工作时段开着） | 约 65 小时（每天 8–12 小时，D7 约 3 小时） | 约 ¥130 |
| 偶尔再租一张 4090 并行（D5–D6） | 约 10 小时 | 约 ¥20 |
| SFT 数据的 API 费用（D09，如果用） | — | ¥10–30 |
| **合计** | | **约 ¥150–200** |
| 其中真正在算的 GPU 时间（§3 的逐日预算） | 25–31 小时 | 约 ¥50–62 |

比原先的 ¥60–95 多出的约 ¥70–100，买的是两样东西：
- 不用为 Mac 做额外适配（换位置编码实现、MPS 不支持 float64 只能用 CPU 慢跑）；
- 不用频繁开关机，也就不会出现"关机后再开机没有空闲卡"的问题。

**可以考虑包周**：AutoDL 包年包月会一直保留 GPU，关机也不会被别人占用；不用了可以转按量计费，按已使用的天数退款（帮助文档「转换计费方式」）。租卡时看一下算力市场的包周价格：**如果不高于 ¥140 左右**（约等于按量计费 70 小时），就直接包周。

§2、§3 的逐项卡时仍然有效，用来估计每个任务要跑多久、安排先后顺序。

## 1. 计费规则（已核实 AutoDL 帮助文档）

| 规则 | 内容 | 对我们的影响 |
|---|---|---|
| 按量计费 | 开机计费、关机停止，按开关机时间算，精确到秒；不看 GPU 是否在用 | 调试、写代码都别开着 GPU 实例 |
| 关机后 GPU 不保留 | 下次开机可能没有空闲卡，数据保留 | 选空闲卡多的地区；没卡时可以克隆实例到别的主机 |
| 无卡模式 | 0.5 核、2GB 内存、无 GPU，¥0.1/h；同一账号同时只能开一个 | 配环境、下载 checkpoint、传代码都用它 |
| 数据盘 | 免费 50GB（`/root/autodl-tmp`），扩容按天计费，关机也收费 | 不扩容；checkpoint 只存权重，不存优化器状态 |
| 自动关机 | `python run.py; /usr/bin/shutdown` | 长任务跑完立刻停止计费 |
| 单价 | 文档只写"以网站显示的现价为准" | **¥2/h 是假设**，租卡时按算力市场的实际价格乘卡时即可 |

包周 vs 按量：见 §0。按量计费只为开机时长付钱，但关机后 GPU 不保留；包周一直保留 GPU，用不完可以转按量退款。

## 2. 单位成本（估计，D1 校准）

| 单位 | 估计值 | 依据 |
|---|---|---|
| 新采样器，每条序列每走一步 | 约 1.25 ms | 4090 bf16 前向，省掉大部分输出层计算，batch ≥ 64 |
| 原版采样器，同上 | 3.3–5.1 ms | 前向 + 全量 float64 采样，batch 16 |
| 训练，每条序列前向 + 反向 | 约 5.2 ms | 前向的约 3 倍 |
| 一次全量 test（1319 题，256 步） | 约 7 分钟 | 新采样器 |
| 一次 dev（1000 题，256 步） | 约 5 分钟 | 新采样器 |
| 一个 RL 步（128 条 × 128 步 rollout + 训练） | 约 29 秒 | rollout 约 20 秒，训练约 5 秒，执行代码打分约 3 秒 |

任何任务的开销 = 题数 × 每题样本数 × 步数 × 单步耗时 × 单价。D1 测出真实的单步耗时后，代入这个公式就能重算所有预算。

## 4. 使用规则（10-30 修订：不刻意省钱，只防止明显浪费）

1. **代码在本地改（git 管理），rsync 到服务器后直接在 4090 上跑。** 不在 Mac 上执行代码。同步只要几秒钟。
2. **工作时段实例一直开着**，不需要为了省钱频繁关机。
3. **只防两种明显的浪费**：
   - 睡觉或长时间离开（超过半天）且没有任务在跑：关机。包周的话不用关。
   - 夜里跑长任务：日志写到文件，在 tmux 里跑。是否在命令末尾加 `; /usr/bin/shutdown` 跑完自动关机，看计费方式：按量计费建议加；包周不用加。
4. **checkpoint 只存权重**（约 0.35–0.7GB），不存优化器状态，避免撑满 50GB 免费数据盘。
5. **每次运行把卡时记进 [06-进度.md](06-进度.md)**，花费按天粗略记一笔即可。
