# Take-home-exam 大作业（5-7天内完成，很有难度）

> 原题存档（2026-10-29 收到）。

## 任务说明

### 任务概览

围绕 TinyGSM 和 Diffusion / Flow 语言模型，从以下两个方向中**任选其一**完成。

**可选择任意 DLM / Flow 语言模型，不限于下方参考模型；不能选择自回归（AR）模型。**

请阅读所选模型的相关论文和代码，理解其训练目标、损失函数和生成过程。我们鼓励结合前沿研究，自主设计实验并验证自己的想法。

### 方向一：基于预训练模型进行 SFT 和 RL

- **选择预训练模型**：选择一个 DLM / Flow 语言模型的预训练 checkpoint。可使用下方仓库中在 TinyGSM 上训练的 Duo、MDLM、FLM 等模型，也可自行选择其他符合要求的模型。
- **实现监督微调（SFT）**：选择合适的数据，完成数据处理、训练和评测。
- **探索强化学习（RL）**：设计并尝试适用于所选模型的 RL 方法，说明奖励函数、训练方法及选择依据。
- **对比实验结果**：在统一评测设置下，比较原始 checkpoint、SFT 后及 RL 后的模型表现，分析提升或退化的原因。

### 方向二：从头预训练 Diffusion / Flow 语言模型

- **从头训练模型**：使用 TinyGSM 数据集，从随机初始化开始训练一个约 170M 参数的 Diffusion 或 Flow 语言模型。
- **设计并实现改进**：重新设计噪声调度（noise schedule）、损失函数（loss function），或尝试优化器及其他训练技巧，说明你的设计思路。
- **进行公平对比**：选择一个 Diffusion / Flow 模型训练方案作为 baseline，与改进方案均从头训练。保持训练数据、训练 token 数和评测设置一致，对比 benchmark 分数，并记录计算开销。
- **分析实验结果**：结合训练曲线和评测结果，解释改动是否有效，以及可能的原因。

### 参考资料

- Hugging Face 模型与预训练 checkpoints：可使用其中 `tinygsm/` 下的 Diffusion / Flow 模型 checkpoints。https://huggingface.co/jdeschena/s-flm
- GitHub 仓库：包含相关模型的训练、采样和评测代码。https://github.com/jdeschena/s-flm
- 所选模型的相关论文，以及你认为有帮助的最新研究。

### 数据集与评测

- **预训练数据**：TinyGSM。https://huggingface.co/datasets/TinyGSM/TinyGSM
- **SFT / RL 数据**：可自行选择与数学推理任务匹配的数据集，说明选择和处理方式。
- **评测**：使用 GSM8K，可参考上述仓库的评测脚本，也可补充其他 benchmark。训练、调参和最终测试的数据应分开。
